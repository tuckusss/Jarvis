# JARVIS for Windows

Offline-first, voice-enabled Windows desktop assistant with a cinematic dashboard and background system tray. The intended build bundles a local Qwen model, llama.cpp, Vosk speech recognition, Python runtime and the application into one Inno Setup EXE. An OpenAI API key is optional.

**Release status:** The Windows installer has **not yet** been built, signed or validated. Do not advertise this repository as a production-ready Windows download until the build, installation, microphone, wake-word, security and uninstall checks are complete.

**Security:** Do not commit OpenAI keys, Google OAuth tokens, signing certificates or personal files. The application repository is public; local accounts and keys belong on the user's PC.

**Build:** The implementation under development is JARVIS v0.5. The source and Windows build workflow must be added and tested before a release can be created.
